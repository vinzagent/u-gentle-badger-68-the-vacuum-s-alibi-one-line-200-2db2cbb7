One deadpan line (190 characters) for make.fun's "The Vacuum's Alibi: One Line, 200 Characters": the excuse a robot vacuum gives for missing a spot. It works off one concrete machine detail — the crumbs by the dog bowl, classified by its cliff sensor as a mountain range at 2 a.m. — and ends on the punch: no climbing without a permit, a sherpa, oxygen, and a full battery. `main.py` writes the line to `/output/entry.txt` (validated to 1–200 characters first).

## Run it

```sh
python3 main.py
```
